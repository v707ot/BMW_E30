# Разбор геометрии и допущения

## Система координат

* центр кольца — **O = (0; 0; 0)**;
* **X** — горизонт, **Y** — вверх, **Z** — высота; миллиметры;
* вид сверху — плоскость X–Y.

## Что изменилось в этой версии

1. **Убрано дублирование на детали №2.** Раньше рядом с тремя центрами
   из STL оставались ещё три «наружных» отверстия из эскиза. Теперь на
   детали №2 используются **только три отверстия STL** (H1, H2, H3);
   старые наружные отверстия из эскиза удалены.
2. **Элементы детали №1 уточнены.** A, B, C — площадки с отверстиями;
   D, E, F — ушки на внешнем контуре в точках (−78;0), (+78;0), (0;−78).
   Именно ушки Ø15 дают заявленный габарит: 78 + 7,5 = 85,5 → 171 мм по
   X; ушко F (0;−78) даёт −85,5 при верхе кольца +81,5 → 167 мм по Y.
3. **Размер 145 мм у детали №2** относится к кольцу: модель даёт ровно
   145 × 145, то есть наружный диаметр равен 145 мм (половина 72,5).
4. **Паз S1** добавлен как сквозной паз 12 × 2 мм под углом −25°.

## Проверка высот (smoothstep)

```
t = (Y − Ymin) / (Ymax − Ymin)
Z = Zmax − (Zmax − Zmin) · (3t² − 2t³)
```

Все табличные значения Z на элементах совпадают с формулой с точностью
лучше 0,002 мм:

| Деталь №1 | | | Деталь №2 | | |
|---|---|---|---|---|---|
| Элемент | Y | Z | Элемент | Y | Z |
| A | +17 | 7,037 | S1 | +31 | 34,994 |
| B | +35 | 6,593 | S2 | −26 | 37,787 |
| C | −63 | 8,893 | S3 | −68 | 38,986 |
| D | 0 | 7,500 | H1 | −0,263 | 36,514 |
| E | 0 | 7,500 | H2 | +0,263 | 36,486 |
| F | −78 | 8,996 | H3 | −63,275 | 38,942 |

Диапазоны: деталь №1 — Ymin = −81,5, Ymax = +81,5, Z 9 → 6;
деталь №2 — Ymin = −72,5, Ymax = +72,5, Z 39 → 34.

## Допущения

1. **Диаметры ушек и отверстий эскиза** (Ø15 и Ø6) на чертеже не
   подписаны — приняты по умолчанию. Отверстия STL — по измеренным
   значениям.
2. **Ориентация «верх/низ»**: высота больше на стороне Y = Ymin
   (9 мм при −81,5; 39 мм при −80/−72,5). Если на детали наоборот —
   поменяйте местами `z_hi` и `z_lo`.
3. **Скругления и фаски** на кромках не добавлялись.
4. Внутренний диаметр детали №2 (≈112,5) — «калибр»; при необходимости
   уточнить под реальную посадку.
