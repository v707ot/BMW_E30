# Разбор геометрии и допущения

## Система координат

* центр кольца — **O = (0; 0; 0)**;
* **+X** вправо, **−X** влево; **+Y** вверх, **−Y** вниз;
* **Z = 0** — плоскость нижней стороны;
* миллиметры; вид сверху — X–Y.

## Состав деталей (финальная спецификация)

Каждая деталь — кольцо с шестью площадками:

* **A, B, C** — три большие крепёжные зоны (площадка Ø15) со сквозным
  отверстием Ø10,1588;
* **D, E, F** — три сплошные площадки (Ø11) без отверстий.

Малых отверстий и пазов нет.

| Элемент | Деталь №1 | Деталь №2 |
|---|---|---|
| Большие крепёжные зоны | 3 | 3 |
| Малые соседние отверстия | 0 | 0 |
| Плоские площадки | 3 | 3 |
| Дополнительный паз 12 × 2 | 0 | 0 |

## Как получаются габариты

Сплошные площадки D, E, F (Ø11) выходят за кольцо и задают габариты —
подгонка не нужна, всё сходится из координат:

**Деталь №1.** D и E (Ø11) в точках (±80; 0): крайние точки по X —
80 + 5,5 = **85,5** → ширина ровно **171 мм**. F (0; −80) доходит до
Y = −85,5, а верх кольца +81,5 → габарит по Y **167 мм**.

**Деталь №2.** D и E (Ø11) в точках (±67; 0): 67 + 5,5 = **72,5** →
ширина ровно **145 мм**. F (0; −67) доходит до −72,5, верх кольца +67,5
→ габарит по Y **140 мм**.

Проверка модели: габаритные боксы равны
`171,00 × 167,00 × 9,00` и `145,00 × 140,00 × 39,00` мм.

## Большие зоны детали №2

Координаты A, B, C перенесены из STL и **повёрнуты на −30°** относительно
исходной системы STL, чтобы совместиться с ориентацией второго эскиза:

| Метка | X | Y |
|---|---|---|
| A | −54,929 | +31,410 |
| B | +54,929 | −31,410 |
| C | −31,410 | −54,929 |

Ø10,1588 — измеренный диаметр круглой зоны в STL.

## Проверка высот (smoothstep)

```
t = (Y − Ymin) / (Ymax − Ymin)
Z = Zmax − (Zmax − Zmin) · (3t² − 2t³)
```

Все табличные значения совпадают с формулой с точностью лучше 0,002 мм:

| Деталь №1 | | | Деталь №2 | | |
|---|---|---|---|---|---|
| Метка | Y | Z | Метка | Y | Z |
| A | +17 | 6,997 | A | +31,410 | 34,826 |
| B | +35 | 6,568 | B | −31,410 | 37,961 |
| C | −60 | 8,812 | C | −54,929 | 38,784 |
| D | 0 | 7,446 | D | 0 | 36,366 |
| E | 0 | 7,446 | E | 0 | 36,366 |
| F | −80 | 8,991 | F | −67 | 38,978 |

Диапазоны: деталь №1 — Ymin = −85,5, Ymax = +81,5, Z 9 → 6;
деталь №2 — Ymin = −72,5, Ymax = +67,5, Z 39 → 34.

Обратите внимание: у детали №1 контрольные точки высоты даны до Y = −85,5
(низ), что совпадает с крайней точкой площадки F, а сверху — до +81,5
(верх кольца). Поэтому диапазон smoothstep берётся [−85,5; +81,5].

## Допущения

1. **Диаметры площадок** (Ø15 для зон A–C, Ø11 для D–F) восстановлены
   примерно по эскизу; отверстия Ø10,1588 — по STL.
2. **Диаметры основы детали №2** (Ø135 и Ø112,5) — предварительные
   оценки по пропорциям рисунка; отдельно не подписаны.
3. **Ориентация «верх/низ»**: высота больше на стороне Y = Ymin (9 мм
   и 39 мм). Если на детали наоборот — поменяйте местами `z_hi` и
   `z_lo`.
4. **Внутренняя ступень** внутри больших зон STL (высота/глубина) не
   подтверждена — в модели отверстие сквозное.
5. **Скругления и фаски** на кромках не добавлялись.
